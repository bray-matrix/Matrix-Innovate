4. CAPACITY CALCULATION
--------------------------------------------------

Implement deterministic server-side capacity calculations.

For named resources:

allocatedPercent =
sum of active assignment allocationPercent for the selected/current timeframe

availablePercent =
100 - allocatedPercent

Flag:
- Overallocated when >100%
- Near Capacity when >=85% and <=100%
- Available when <85%

If weeklyCapacityHours and plannedHours are available, expose them but do not create a complicated forecasting engine yet.

For department-only demand:
- report demand separately
- do not falsely attribute it to named-resource capacity
