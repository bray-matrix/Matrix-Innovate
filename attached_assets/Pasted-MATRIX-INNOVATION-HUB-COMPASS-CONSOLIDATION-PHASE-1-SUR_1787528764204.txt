5. INITIATIVE -> PROJECT PROMOTION
--------------------------------------------------

Add a controlled workflow allowing an Innovation initiative to become an execution project.

On an initiative detail screen, when appropriate, provide:

"Create Project"

This must:

- create a real Project row
- preserve the Initiative row
- populate project.initiativeId
- copy appropriate fields such as:
  - title/name
  - description
  - priority
  - business owner / sponsor where appropriate
- allow the user to choose:
  - project type
  - organization if applicable
  - client if applicable
  - program if applicable
  - primary owner
  - target date

After creation:
- show a link from Initiative -> Project
- show a link from Project -> originating Initiative

Prevent accidental duplicate promotion unless the user explicitly chooses to create an additional related project.

Do NOT convert/delete/mutate the original initiative into a project.

The lifecycle is:

Idea / Innovation
        ->
Approved for Execution
        ->
Project

The initiative remains the innovation/business-case record.
The project becomes the execution record.
