# Innovation Hub v1.6.9 — saved Initiative integration

## Save boundary diagnosis

The Review screen already collects title, Initiative Type/category, department, submitter, optional owner/sponsor, narrative and assessment. There is no separate required-metadata Save wizard in this path. Required field validation stays on Review. Governance, tracking and project planning remain after Save.

Before this release, serializeForSave appended labelled value, risks, next steps, candidates, unknowns/discovery and context to desiredOutcome. Create persisted score zero and v0.1.0; a second PATCH stored reviewed scoring and produced v0.1.1. This was not an automatic Recalculate operation.

A production SELECT of reference INI-0017 confirmed its flattened Desired Outcome, score 45 and v0.1.1. No production record was changed.

## Mapping

| Reviewed Brief | Saved destination |
| --- | --- |
| Title, type, department, submitter, owner, sponsor | Existing metadata columns (type is category) |
| Executive Summary | executiveSummary |
| Problem / Opportunity | problemStatement |
| Current Process | currentProcess |
| Desired Outcome only | desiredOutcome |
| Approach / prototype | aiConcept / prototypeGoal |
| Established success measure | successMetric |
| Numeric value estimates | Existing hours/revenue/savings fields |
| Qualitative value, risks, next steps | reviewedBrief; separate editable canvas/intelligence sections |
| Suggested measures, critical/discovery unknowns, supporting context | reviewedBrief; separately presented, editable supporting sections |
| Intake readiness | reviewedBrief assessment; displayed separately from score |
| Current score/components/priority | Existing deterministic scoring fields |
| Jira origin | Existing verified relationship; brief also retains supporting provenance |

One optional nullable reviewed_brief JSONB column was added in development. Existing core columns remain authoritative for later edits and promotion; a stale Brief snapshot must never overwrite them. Full reviewed semantic structure is runtime-validated and bounded. Existing safety scans inspect nested content. No production migration script or startup DDL was introduced; schema adoption occurs with the normal manual Publish process.

Create now saves scoring, the reviewed Brief, one initial v0.1.0 history snapshot and private-draft completion atomically. The owned draft lock and saved receipt make repeat creates return the existing Initiative. The frontend no longer issues the second scoring PATCH. Existing no-op/version rules remain.

## Responsibilities

- Deterministic: scoring, thresholds, readiness, lifecycle, validations, similarity and useful recommendation rules.
- Shared AI: existing interview synthesis only; no new provider, prompt change or calls.
- Reviewed content: authoritative qualitative value, risks and next steps. Core and supplemental edits remain available through existing Edit Mode.
- Intelligence: self-exclusion already existed and now has a focused regression; unsupported mandatory legal/security sign-off removed; qualitative value is retained independently of unknown dollars/hours; governance advice uses current state, unknowns, ownership/sponsor, intake context and assessment.
- Confidence: existing formula retained, explicitly described as an unvalidated recommendation heuristic, not measured probability or intake readiness.
- No score weights or readiness thresholds changed; accepted risk synthesis untouched.
