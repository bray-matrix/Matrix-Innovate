The production report says an intermittent first click appears to do nothing and a second succeeds. **This session did not reproduce that sequence. No root cause of the historical intermittent behavior is confirmed.** A source-level enabled-control/handler mismatch was confirmed for Draft My Initiative and corrected without retries or duplicate submissions. The entries below distinguish what the code guarantees *if an enabled button's click event reaches its handler* from what still requires an authenticated browser trace. A disabled button has no handler entry; these are not evidence of a lost click.

The table traces source branches, **not observed YES/NO values for production clicks**. The confirmed mismatch means a Draft click while Save Draft was pending could enter its handler and return with no Draft request/transition; it does **not** prove that this caused the historical production symptom. The crucial unknowns for all seven actions are whether the *first* pointer event reaches the handler, whether validation passes on that particular click, whether a network request is created/completes, and whether the following UI/download/navigation occurs. The corresponding second-click difference is likewise **not reproduced**, except the earlier successful one-click export baseline. In particular, a state setter or mutation call in source does not prove a browser request completed.

Other guarded actions checked: Review Save's synchronous ref pairs with parent `saving` (both Save placements disable), and export ref pairs with `exporting` (both buttons disable); linked-work Jira `confirming` pairs with `confirmPending`; promotion `promoteInFlight` pairs with `submitting`; interview Save Draft and Draft's `finishInFlight` pair with `savingDraft` and `finishing`. No other confirmed enabled-versus-guard mismatch was found in these controls. The pre-render interval before React commits a disabled state still has synchronous refs protecting against duplicate requests; a click suppressed in that interval is not evidence of the reported first-click failure.
